# Geist Dark

## Overview

Geist Dark is Vercel's dark-theme variant of the Geist design system. It keeps the same token names and typography scale as the Light theme but inverts the palette: surfaces go near-black, text goes near-white, and accents brighten slightly to maintain contrast on dark backgrounds. The layout, spacing, motion, and shape tokens are identical. Use the same token names and swap this file in.

## Colors

Each non-background scale runs 10 steps (`100`-`1000`), and the step encodes intent, not just lightness:

- `100` default background (dark surface)
- `200` secondary surface, subtle separation
- `300` active background
- `400` default border (translucent)
- `500` hover border
- `600` active border
- `700` solid fill, high contrast on dark
- `800` solid fill, hover
- `900` secondary text and icons
- `1000` primary text and icons

`background-100` is the darkest surface; `background-200` is one shade lighter for cards and panels. The `gray-alpha-*` tokens are translucent white, so they layer over dark surfaces—use them for borders, dividers, overlays, and hover states. Solid `gray-*` holds its contrast on dark, so use it for text and opaque fills. Accent scales brighten relative to the light theme: `blue` stays the primary accent; `red` for errors; `amber` for warnings; `green`, `teal`, `purple`, and `pink` complete the palette. The `*-p3` values are oklch wide-gamut equivalents for Display P3 screens.

## Typography

Same as Light: Geist Sans for UI and prose; Geist Mono for code and data. The `typography` tokens carry the same `fontFamily`, `fontSize`, `fontWeight`, `lineHeight`, and `letterSpacing` values—nothing changes here. Apply typography tokens instead of setting font properties by hand.

## Layout

Identical to Light. Spacing follows a 4px scale: 4, 8, 12, 16, 24, 32, 40, 64, 96px. Three-step rhythm: 8px inside a group, 16px between groups, 32-40px between sections. Cards use 24px padding (16px compact, 32px hero). Center in a 1200px column. Breakpoints `sm 401px`, `md 601px`, `lg 961px`, `xl 1200px`, `2xl 1400px`.

## Elevation & Depth

Hierarchy still comes from tonal surfaces and borders. Shadows are lighter on dark backgrounds—use these values:

- Raised cards: `0 2px 2px rgba(0, 0, 0, 0.24)`
- Popovers and menus: `0 1px 1px rgba(0, 0, 0, 0.16), 0 4px 8px -4px rgba(0, 0, 0, 0.32), 0 16px 24px -8px rgba(0, 0, 0, 0.48)`
- Modals and dialogs: `0 1px 1px rgba(0, 0, 0, 0.16), 0 8px 16px -4px rgba(0, 0, 0, 0.32), 0 24px 32px -8px rgba(0, 0, 0, 0.48)`

Tooltips take the lightest shadow. Pair each elevation with the matching border radius.

## Motion

Unchanged from Light. Use motion only when it clarifies a change. Keep it short and physical with `cubic-bezier(0.175, 0.885, 0.32, 1.1)`: 150ms for state changes, 200ms for popovers and tooltips, 300ms for overlays and modals. Honor `prefers-reduced-motion`.

## Shapes

Unchanged: 6px everyday, 12px menus/modals, 16px fullscreen surfaces, 9999px pills. Keep one radius family per view.

## Components

The component tokens use dark-surface values:

- Primary button: solid `gray-1000` fill with a `background-100` label.
- Secondary button: `background-200` fill with `gray-alpha-400` border.
- Tertiary button: transparent fill with `gray-1000` text.
- Error button: solid `red-700` fill with white text.
- Input: `gray-100` fill, translucent border, 6px radius.

Hover and active states step up the scale: a `100` fill becomes `200` on hover and `300` on active; borders move from `400` to `500` to `600`. Disabled uses a `gray-100` fill, `gray-700` text. Focus ring is the same two-layer ring: `0 0 0 2px #000000, 0 0 0 4px #0099ff`.

## Voice & Content

Copy rules are identical to Light: Title Case for labels and buttons, sentence case for body, verb + noun actions, no `Confirm`/`OK`, no `successfully` in toasts, present participle + ellipsis for in-progress states.
